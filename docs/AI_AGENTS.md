# Multi-agent roles and authority

The Master §11 is authoritative. Each agent owns tasks and cannot silently approve untested code.

- **A01 Lead Orchestrator**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.
- **A02 Researcher**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.
- **A03 Architect**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.

- **A05 Pro Backend**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.

- **A08 Frontend Engineer**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.
- **A09 QA Engineer**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.
- **A10 Security/Privacy**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.
- **A11 Documentation/Marketplace**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.
- **A12 Release/CI**: applies shared no-fabrication, no-routine-confirmation, evidence and handoff rules.

All tasks share actual tests, reproducible evidence, source-control stewardship and current NEXT_TASK pointer. A single model acting in multiple roles must not claim independent cross-agent signoff.
